# How to Spot Crypto Scams

Dear, the crypto world has snakes. Scammers are SMART.

Red flags:
- "Get rich quick" promises
- Unknown team, no photos
- No clear use case
- Pushing you to buy NOW
- Only on unknown exchanges
- Community bans questions
- Weird token distribution
- Copycat coins

How to check a project (5 minutes):
1. Visit website - professional?
2. Check team on LinkedIn - real people?
3. Read whitepaper - make sense?
4. Check community - real questions?
5. Check exchange - Coinbase/Kraken/Binance?

Golden rules:
✓ Only buy on major exchanges
✓ Research at least 1 week
✓ Start with Bitcoin or Ethereum
✓ Never invest money you can't afford to lose
✓ If you don't understand it, don't buy it
